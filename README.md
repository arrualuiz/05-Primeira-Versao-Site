# Personal Dashboard

Um painel pessoal (dashboard) intuitivo e centralizado para acompanhamento diário de informações úteis, feeds de notícias esportivas e acesso rápido a atalhos do dia a dia.

## 🚀 Funcionalidades

- **Relógio e Calendário:**
  - Exibição em tempo real de hora, dia da semana e data.
  - Calendário mensal interativo com destaque para o dia atual e contador de semanas do ano.
  - Notificações de datas comemorativas / lembretes pessoais.

- **Widgets de Informação:**
  - **Clima:** Temperatura atual, condições do tempo, velocidade do vento e horário da última atualização.
  - **Feeds de Notícias:** Seções dedicadas para acompanhar as últimas notícias do Coritiba e do Santos.

- **Central de Links Rápidos:**
  - **Coisas / Links:** Acesso rápido ao Diário OneDrive, Arrua, gerenciamento de Senhas, Rotina e afazeres.
  - **Contabilidade / Links:** Atalhos diretos para formulários de contabilidade, controle de dívidas/pendências, lista de compras e serviços.

## 🛠️ Tecnologias Utilizadas

- **HTML5 / CSS3:** Estrutura flexível em cards com suporte a Dark Mode.
- **JavaScript:** Manipulação de datas, lógica de relógio/calendário e consumo de dados de clima/notícias.
